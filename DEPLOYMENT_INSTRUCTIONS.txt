SECURITY & HARDENING FEATURES INCLUDED IN .HTACCESS:
--------------------------------------------------------------------------------
✓ Enforces HTTPS automatic 301 redirection.
✓ Script Execution Lockdown: Completely disables execution of PHP, Python, Perl,
  and shell scripts (.php, .phtml, .cgi, .sh, etc.) in the web directory.
✓ Directory Browsing Disabled (Options -Indexes).
✓ Hidden File & Dotfile Protection: Blocks direct web access to sensitive files (.git, .env, etc.).
✓ Enterprise Security Headers:
    - X-Content-Type-Options: nosniff
    - X-Frame-Options: SAMEORIGIN
    - X-XSS-Protection: 1; mode=block
    - Referrer-Policy: strict-origin-when-cross-origin
    - Permissions-Policy: camera=(), microphone=(), geolocation=(), payment=()
    - Strict-Transport-Security (HSTS): 1 Year (max-age=31536000)
✓ Performance Caching: High-efficiency browser caching (mod_expires) for WebP/PNG/fonts
  and GZIP/Brotli compression (mod_deflate).
✓ Form Leads: All contact and calculator forms dispatch asynchronously via secure
  HTTPS webhooks to Make.com/CRM, protected by invisible anti-bot honeypots.
  Zero PHP mail() execution on this shared host, preventing any server IP blacklisting.
